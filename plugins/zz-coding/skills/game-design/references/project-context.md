# 项目专属数据（Project Context）

## 概述

本文档包含当前项目的专属数据和设计模式。更换项目时整体替换此文件即可，其他 reference 文件无需改动。

本文档从项目现有策划方案中提炼可复用的设计模式。这些模式不是"必须套用的模板"，而是**经过验证的结构性参考**，帮助 AI 在生成 MVP 草稿时选择合适的骨架。

> 使用原则：模式是起点不是终点。选择模式后必须根据具体设计目的做适配，不能照搬。

## 零、游戏核心框架（设计前必读）

### 核心循环：Coin Master 模式 × 钓鱼

本游戏的核心循环类似 Coin Master，用**钓鱼**替代老虎机：

```
体力（核心货币）→ 钓鱼 → 钓到鱼/活动代币 → 参与各循环活动 → 获取奖励
                                                                ↑
                                              体力用完 → 购买体力/代币礼包（核心付费点）
```

**基础世界结构**：
- 40 个钓场，每个钓场 12 条独属鱼种
- 玩家在钓场之间推进，钓鱼是一切活动的资源入口

**体力经济**：
- 体力 = 核心货币（类似 Coin Master 的能量）
- 玩家基本每天消耗完所有体力
- **卖体力是主要变现手段**——单独卖体力，或捆绑活动代币+体力作为礼包
- 所有循环活动最终都消耗体力：体力 → 钓鱼 → 产出活动资源 → 推进活动进度

**目标活动与钓场的关系**：
- 每 3 天轮换一次目标活动
- 目标活动会**改变钓场鱼种**（如原有鱼变成材质鱼、信物鱼）或新增活动专属鱼
- 玩家钓到活动鱼 → 积分/累积进度 → 达标领奖
- 目标活动是连接核心循环（钓鱼）和各循环活动的**桥梁**

**循环活动的体力消耗链条**：
- 循环I类活动（如拼图、Bingo）：消耗体力钓鱼 → 获取活动代币 → 用代币解锁活动进度（一轮约消耗 1.5 万体力）
- 付费逻辑：玩家体力/代币用完但想完成活动 → 购买含体力+活动代币的礼包

### 每点体力返利结构（代币投放占比）

玩家每消耗1点体力，系统通过不同活动渠道返还各类资源。以下是各渠道的返利占比（2025.12.9 数据）：

**非循环渠道（基础返利来源）**：

| 渠道     | 返体力(含钻石) | 返钞票  | 返鱼卡  | 返钓箱(鱼竿) | 树脂   | 返循环I代币 | 返循环II代币 |
| ------ | -------- | ---- | ---- | ------- | ---- | ------ | ------- |
| 目标奖励活动 | 15.0%    | 8.0% | —    | —       | —    | 12.0%  | 12.0%   |
| 排行榜    | 6.0%     | 4.0% | 4.0% | —       | 2.0% | —      | —       |
| 建造&账号  | 3.0%     | 3.6% | 5.0% | 6.0%    | —    | 2.0%   | —       |


> **关键发现**：目标奖励活动是循环I/II代币的**主要投放渠道**（各12%），也是体力回流最大的渠道（15%）。这意味着目标活动不仅是体验桥梁，更是整个代币经济的供给引擎。

**循环活动渠道（活动自身返利）**：

| 活动类型 | 总返利率 | 返体力(含钻石) | 返钞票 | 返鱼卡 | 返钓箱(鱼竿) | 树脂 |
|---------|---------|-------------|--------|--------|-------------|------|
| 循环I类 | 12.8% | 8.1% | 1.0% | 1.2% | 1.9% | 0.5% |
| 循环II类 | 11.0% | 7.0% | 1.7% | 0.6% | 1.0% | 0.7% |
| 循环III类 | 12.1% | 9.4% | 0.7% | 0.6% | 1.4% | 0.0% |
| 社交类 | 11.2% | 6.4% | 1.0% | 1.8% | 1.6% | 0.5% |

> **规律**：
> - 各循环活动的总返利率非常接近（11%~13%），说明返利率是一个**被刻意控制的平衡参数**
> - 循环III类体力返还最高（9.4%），但其他品类返还最低——说明循环III侧重"让玩家继续玩"，而非分散资源
> - 社交类鱼卡返还最高（1.8%），体现社交活动与钓鱼收集体验的关联
> - 循环I类整体最均衡，各品类都有回流

**设计新活动时的返利约束**：
- 新活动的总返利率应控制在 **11%~13%** 区间内，与现有活动保持平衡
- 返利的品类分配要匹配活动定位（如社交类多返鱼卡，循环III多返体力）
- 如果新活动属于循环I/II，其代币主要由目标奖励活动投放（12%），活动自身不产生循环代币

> **设计新活动时的核心约束**：任何新活动都必须接入体力经济。如果一个活动不消耗体力（直接或间接），它就脱离了核心付费链条，变现能力会大打折扣。

### 3天周期 × 7 槽位并行结构

游戏以 **3 天为一个活动周期**，每个周期内同时运行 7 个活动槽位：

| 槽位 | 类型 | 周期 | 说明 |
|------|------|------|------|
| 目标活动 | 目标 + 阶梯奖励 | 3天 | 标鱼类/信物类/材质类/特殊鱼类轮换 |
| 循环I | 核心玩法 | 3天 | Boss战/Bingo/Block/弹珠/寻宝/魔药/拼图/对对碰轮换 |
| 循环II | 次核心玩法 | 3天 | 破坏/刮刮乐/靶场/罐头/矿石寻宝轮换 |
| 循环III | 抽奖类玩法（内含小战令） | 3天 | 幸运魔术/幸运卡牌轮换，每个自带配套小战令（如潜水员体力战令、幸运魔术战令），战令是循环III的内置付费层，不独立设计 |
| 社交 | 社交玩法 | 3天 | 伙伴建造/挑战赛/Rush轮换 |
| 宝箱转盘 | 配套付费 | 3天 | 沙丘礼包/Disco/扭蛋机/锁链礼包轮换 |
| 3天礼包 | 付费礼包 | 3天 | 特殊礼包链/砍价礼包/储蓄罐轮换 |

> 所有槽位统一 3 天周期。小战令不是独立槽位，是循环III的内置组件。

**设计新活动时必须明确它要填入哪个槽位**，这决定了：
- 活动周期（统一3天）
- 与同期其他活动的资源竞争关系
- 在整体收入结构中的定位

| Bingo | $0.43 | $15.92 | 2.7% | 高付费率但付费深度低，广覆盖型 |
| Block | $0.41 | $31.51 | 1.3% | 付费深度高但付费率低，核心付费型 |
| 弹珠 | $0.37 | $34.78 | 1.1% | 最高ARPPU，深度付费但覆盖窄 |
| 寻宝 | $0.37 | $32.03 | 1.2% | 类似弹珠，深度付费型 |
| 魔药 | $0.33 | $29.10 | 1.1% | 中等表现 |
| 拼图 | — | — | — | 旧版数据，新版数据待定 |

**玩法说明**（怎么玩）：

| 活动 | 核心机制 | 操作方式 |
|------|---------|---------|
| Boss战 | 消耗体力钓鱼获取攻击代币 → 转盘决定武器（导弹/激光/治疗/护盾） → 15分钟间隔攻击深海Boss | 转盘选择+限时Boss战，策略性中等 |
| Bingo | 消耗体力钓鱼获取Bingo代币 → 代币填充格子 → 完成行/列/斜线获得奖励 | 一键点击，无策略（近失期待感——"差一格就连线"驱动持续投入） |
| Block | 消耗体力钓鱼获取活动代币 → 拖拽方块填满行/列触发消除，收集材料合成物品 | 拖拽操作，有空间策略 |
| 弹珠 | 消耗体力钓鱼获取弹珠 → 拉力度发射，利用反弹收集奖励，有弹道预测线 | 拉力度+发射，有操控感但无实际策略 |
| 寻宝 | 消耗体力钓鱼获取探索代币 → 在4~6个格子中选择翻开寻找宝物 | 选格翻开，中度策略（每次位置不同） |
| 魔药 | 消耗体力钓鱼获取魔药代币 → 按规则合成魔药通关，自动生成关卡，有新老玩家分轨数值 | 点击合成，轻度策略 |
| 拼图 | 消耗体力钓鱼获取拼图代币 → 代币兑换碎片放入网格（2x2→3x3→4x4） → 完成图片获取奖励（一轮约消耗1.5万体力） | 放置碎片，操作极简 |
| 对对碰 | 消耗体力钓鱼获取翻牌代币 → 翻转卡牌寻找配对，西部牛仔主题，有套索道具辅助 | 翻牌+记忆，中度策略（考验记忆力） |

**玩法作用**（为什么做、在体系中的价值）：

| 活动 | 体系作用 | 设计价值 |
|------|---------|---------|
| Boss战 | 核心循环代币消耗出口 + 策略性情绪体验 | 通过"策略感+目标感+付费深度"三合一，成为循环I收入标杆。验证了"策略性+目标感的玩法付费表现优于纯进度型"的规律 |
| Bingo | 广覆盖的低门槛参与入口 | 规则极简、全民可玩，拉高整体付费率（2.7%全品类第二），但单用户付费深度有限 |
| Block | 中度策略的深度付费承载 | ARPPU $31.51说明付费用户愿意深度投入，但1.3%付费率说明门槛偏高，适合服务核心付费群 |
| 弹珠 | 操控感体验供给 + 深度付费 | ARPPU最高（$34.78），"拉力度"的操控感幻觉提供差异化体验，但低付费率（1.1%）限制了整体贡献 |
| 寻宝 | 探索体验 + 新鲜感供给 | 满足"新鲜感"情绪维度，探索式体验与其他策略型/进度型形成互补 |
| 魔药 | 新老玩家分层服务 | 唯一有完整新老分轨数值的循环I玩法，验证了分轨模式（W3）在循环I中的可行性 |
| 拼图 | 长周期留存锚点 | 进度推进式设计天然拉长参与周期。已改版为新版，数据待验证 |
| 对对碰 | 记忆策略体验 + 休闲补充 | 记忆类玩法提供中度策略感，考验记忆力，在其他玩法轮换后提供节奏缓冲 |

> **规律**：循环I类中，付费率高（>2%）的活动（Boss战2.6%、Bingo 2.7%）ARPU显著领先。策略性+明确目标感的玩法（Boss战 $0.79）表现最强。

**循环II类**（ARPU 范围 $0.14 ~ $0.29）：

| 活动 | ARPU | ARPPU | 付费率 | 收入特征 |
|------|------|-------|--------|---------|
| 破坏 | $0.29 | $10.37 | 2.8% | 类内标杆——高付费率 |
| 刮刮乐 | $0.18 | $10.96 | 1.6% | 中等 |
| 新靶场 | $0.17 | $8.40 | 2.1% | 付费率尚可但ARPPU低 |
| 矿石寻宝 | $0.17 | $9.28 | 1.8% | 中等 |
| 罐头 | $0.14 | $9.84 | 1.4% | 类内最低 |

**玩法说明**（怎么玩）：

| 活动 | 核心机制 | 操作方式 |
|------|---------|---------|
| 破坏 | 即时打击——拳击主题，三档付费分层（2代币/5代币/10代币），不同档位同时开放，玩家按自身付费能力选择 | 连续点击，即时反馈，操作极简 |
| 刮刮乐 | 刮开覆盖层揭示奖励——多区域分步刮开，有保底机制 | 滑动刮开，操作极简 |
| 新靶场 | 射击目标——点击靶子得分，结果随机，有多种主题皮肤 | 点击射击，无实际策略（类似刮彩票） |
| 矿石寻宝 | 路径选择——地图约20~30个格子，玩家选择最短路径到终点，同时可绕路收集高价值奖励格 | 选路径+取舍判断，中度策略（最短路径 vs 高价值奖励的取舍） |
| 罐头 | 开罐收集——打开罐头获取随机奖励 | 点击开启，操作极简 |

**玩法作用**（为什么做、在体系中的价值）：

| 活动 | 体系作用 | 设计价值 |
|------|---------|---------|
| 破坏 | 即时爽感宣泄出口 + 付费分层标杆 | 付费率2.8%为循环II最高。核心原因是**三档付费分层**（2/5/10代币）让不同消费能力的玩家同时参与不同档位，拉高整体付费率。验证了"付费分层 → 高付费率"的规律，其他循环II活动因缺少分层导致付费表现一般 |
| 刮刮乐 | 低门槛随机惊喜 | 经典C3模式在循环II的实现，提供"花很少时间就可能获得好东西"的轻量体验 |
| 新靶场 | 操控感幻觉体验 | 与弹珠类似，"射击"包装给玩家操控感但结果随机，本质是随机奖励的趣味包装 |
| 矿石寻宝 | 路径策略体验 + 取舍决策 | 循环II中少有的中度策略玩法——"选最短路径还是绕路拿好奖励"的取舍提供真实决策感。这类**选择即收益**的策略设计是未来应多做的方向 |
| 罐头 | 极简参与保底 | 参与成本最低的活动之一，确保即使低活跃玩家也能参与循环II |

> **规律**：循环II类整体ARPU只有循环I类的40-50%，ARPPU约为循环I类的1/3。说明循环II类定位是**轻度参与、低付费门槛**的补充内容。但破坏活动通过**付费分层**（三档代币消耗）拉到了2.8%付费率，说明即使是轻量活动，做好付费分层也能显著提升付费转化。未来循环II新活动应优先考虑付费分层设计。

| 内置战令 | 幸运魔术战令 | $0.41 | $12.46 | 3.3% | 7 |
| 内置战令 | 潜水员体力战令 | $0.63 | $11.56 | 5.5% | 8 |

**玩法说明**（怎么玩）：

| 活动 | 核心机制 | 操作方式 |
|------|---------|---------|
| 幸运魔术 | 不重复转盘抽奖——多档奖池（蓝/紫/橙/红），有路径卡推进高阶奖池 | 点击旋转，选择路径，操作极简 |
| 幸运卡牌 | 翻牌寻奖——先选目标奖励，再翻卡寻找，每次翻牌费用递增，有倍率卡 | 选择+翻牌，操作极简 |
| 配套战令 | Battle Pass 进度轨——随玩法本体参与自动推进，免费轨+付费轨双轨奖励 | 自动推进，购买付费轨一次性决策 |

**玩法作用**（为什么做、在体系中的价值）：

| 活动 | 体系作用 | 设计价值 |
|------|---------|---------|
| 幸运魔术 | 全品类最高付费率的付费转化引擎 | 3.5%付费率 = 全品类之冠（玩法本体），利用"不重复抽奖+路径推进"降低随机挫败感，提高付费意愿 |
| 幸运卡牌 | 广覆盖的低门槛付费入口 | 翻牌机制直觉清晰、参与门槛极低，8次/15期的高频轮换说明是运营主力 |
| 配套战令 | 循环III的内置付费放大器 | 战令付费率（3.3%~5.5%）叠加在玩法本体之上，是整个游戏最强的付费组合。**设计新的循环III玩法时必须同步设计配套战令** |

> **规律**：循环III只有2种玩法高频轮换，品类少但复用率极高。合计ARPU（$0.75~$1.07）实际是全品类最高的单槽位贡献。核心优势 = 广覆盖（高付费率）+ 双层变现（玩法+战令）。

**玩法作用**（为什么做、在体系中的价值）：

| 活动 | 体系作用 | 设计价值 |
|------|---------|---------|
| 伙伴建造 | 社交关系链建设 + 留存锚点 | 出现8次/15期为社交类最高频，说明协作型社交是留存的核心工具。ARPU虽低（$0.14），但其价值在于创造社交羁绊降低流失 |
| 挑战赛 | 竞争性社交压力供给 | 排名+升降级机制提供外部目标感（方法论：社交压力→目标感）。使用机器人调节体验，防止新/弱玩家被碾压 |
| Rush | 短期活跃刺激 | 限时冲刺制造紧迫感，适合在活跃数据低迷时提振短期DAU |

> **规律**：社交类 ARPU 最低，说明其价值不在直接变现而在社交粘性和留存。设计社交活动时不应以收入为目标。

**整体周期收入**：每3天周期合计约 $16k ~ $25k，DAU 约 9000-10000，付费率 12-15%，ARPPU $19-23。

### 设计新活动的收入定位指引

| 目标槽位 | ARPU 基准 | 付费率基准 | 设计侧重 |
|---------|-----------|-----------|---------|
| 循环I | $0.35 ~ $0.80 | 1.0% ~ 2.7% | 策略性 + 明确目标感 → 高ARPU |
| 循环II | $0.14 ~ $0.29 | 1.4% ~ 2.8% | 轻量 + 低门槛 + 付费分层 → 补充内容（破坏验证：分层可拉高付费率） |
| 循环III（含内置战令） | $0.75 ~ $1.07 | 2.5% ~ 5.5% | 随机性 + 内置Battle Pass → 全品类最强付费组合 |
| 社交 | $0.07 ~ $0.14 | 1.6% ~ 1.8% | 社交粘性 → 不以收入为目标 |

## 一、核心循环模式

### 模式 C1：钓鱼概率触发 → 进度奖励（核心循环）

**结构**：消耗体力钓鱼 → 概率触发特殊事件 → 累积进度 → 阶段奖励

这是整个游戏最核心的循环，类似 Coin Master / Monopoly Go 的中间进度奖励机制。

**两个 C1 子系统**：

| 子系统 | 触发方式 | 触发概率 | 进度机制 |
|--------|---------|---------|---------|
| 目标活动 | 钓到目标活动鱼 | ~20% | 钓到活动鱼 → 积分 → 累积进度 → 阶段奖励 |
| 排行榜 | 钓到漂浮瓶 | ~15% | 钓到漂浮瓶 → 触发轰炸/射击 → 获得排行榜代币 → 排名奖励 |

**情绪节奏**：
- 每次钓鱼 = 期待（会不会触发？→ Coin Master 拉杆的核心情绪）
- 触发成功 = 惊喜释放（特殊事件启动）
- 进度累积 = 持续升压（接近阶段目标时最紧张）
- 阶段达标 = 大释放（奖励结算）

**设计要点**：
- **触发概率是核心调控杠杆**——直接影响玩家体力消耗速率和付费压力
- 目标活动是循环I/II活动代币的**主要投放渠道**（各12%），是代币经济的供给引擎
- 目标活动每3天轮换，会改变钓场鱼种（变成材质鱼、信物鱼等），保持新鲜感
- 排行榜通过轰炸/射击提供策略性体验，打破钓鱼的单一节奏
- **目标活动内置付费分层**：活动开启时体力>1000的玩家进入高消耗档位（约10倍代币消耗），奖励同比例放大（约8~10倍），返利比基本不变。小R起步约4~5个目标代币换40体力，大R按比例放大。这种"消耗档位自动匹配"的分层让不同付费层级的玩家在同一活动中各得其所

### 模式 C2：活动代币消耗 → 游玩 → 奖励（循环活动）

**结构**：消耗体力钓鱼 → 产出活动代币 → 消耗活动代币参与循环活动 → 游玩 → 产出奖励

**典型实例**：所有循环I/II类活动（Boss战、Bingo、Block、弹珠、寻宝、魔药、拼图、对对碰、破坏、刮刮乐、靶场、罐头等）

**适用场景**：体力消耗出口——通过活动代币接入核心付费链条

**活动代币来源**：
- 主要来源：目标活动投放（循环I代币12%，循环II代币12%）
- 次要来源：建造&账号（循环I代币2%）
- 活动自身不产生循环代币，代币由 C1（目标活动）供给

**情绪节奏**：
- 活动代币积攒 = 低压力期（随 C1 目标活动自然获取）
- 活动代币消耗进入 = 压力启动点（开始投入）
- 活动游玩过程 = 压力攀升（结果未知）
- 奖励结算 = 释放点（确认收获）
- 活动代币/体力耗尽 = 付费决策点（买不买礼包继续？）

**设计要点**：
- **活动代币由 C1 目标活动投放**，设计新 C2 活动时需确认目标活动的代币投放比例是否覆盖
- 一轮活动的体力消耗要有明确预期（如拼图约1.5万体力/轮），让玩家能规划
- 活动代币获取速率要匹配活动周期（3天内活跃玩家用免费体力能完成基础轮次）
- 付费点 = 活动代币/体力用完但想继续 → 购买体力+活动代币捆绑礼包

### 模式 C3：随机结果 → 即时反馈（抽奖类）

**结构**：消耗活动代币 → 随机结果 → 即时反馈 → 决策（继续/收手）→ 重复

**典型实例**：幸运魔术、幸运卡牌（循环III类）；刮刮乐、靶场（循环II类中的C3变体）

**适用场景**：高付费转化活动，利用随机性驱动情绪

**情绪节奏**：
- 动作前 = 期待（方法论：随机性 = 条件反射式吸引力）
- 结果揭示 = 瞬间释放（好结果 = 惊喜；差结果 = 沮丧但想翻盘）
- 决策点 = 策略性压力（继续投入还是见好就收）

**设计要点**：
- 必须有"差一点就中"的体验设计（near-miss，维持动力）
- 随机结果不能完全看运气，要有策略性选择空间
- 付费加速/增加次数时，注意公平感底线（方法论：价值排序）
- 循环III类 = C3 + 内置战令（W2），是全品类最强付费组合

### 模式 C4：对抗 → 结算（社交竞争类）

**结构**：匹配对手 → 准备/选择 → 对抗过程 → 结算胜负 → 奖惩

**典型实例**：扇耳光（1v1 PVP）、挑战赛（排名竞争）

**适用场景**：社交驱动型活动，需要社交压力提供目标感

**情绪节奏**：
- 匹配 = 期待 + 轻度紧张
- 对抗 = 高压力（输赢不确定）
- 胜利 = 大释放（成就 + 优越感）
- 失败 = 沮丧但要有"差一点就赢了"的感觉

**设计要点**：
- 匹配机制必须保障中坚层体验（方法论：优先保护海豚+高活跃+强社交）
- 高攻击性玩家必须有受限机制（方法论：防止破坏生态）
- 失败体验要可控——不能让玩家感到"被碾压"（方法论：公平感）
- PVP 中可使用 NPC/机器人调节体验（挑战赛已验证该模式）

## 二、新鲜感衰减与应对策略（设计核心难题）

### 问题描述

**重复活动的收入衰减是当前最大的设计挑战**。以 Boss Fight 为例：全新一期冲最高，第二期明显下降，第三期收入仅为第一期的约 50%。玩家对重复性内容感到厌倦，即使主题不同，底层机制相同也会导致兴奋度快速衰减。

### 行业参考：Coin Master 和 Monopoly Go 的做法

**Coin Master 的事件体系**（搜索综合）：
- **多种独立事件类型**同时运转，每种有完全不同的机制：Attack Madness（攻击积分制）、Raid Madness（突袭积分制）、Viking Quest（用金币而非转盘玩独立小游戏）、Balloon Fiesta（限时点击气球小游戏）、Set Blast（卡牌收集加成30%）、Bet Blast（下注翻倍）
- 关键策略：**事件放大核心循环，而不是制造独立侧线**——Attack/Raid Madness 让玩家做更多已有的攻击/突袭行为，Set Blast 让卡牌收集更有价值
- **乘数叠加事件**：Bet Blast 让所有奖励翻倍、Village Mania 折扣建筑升级——这些"加成事件"与主活动叠加运行，改变经济参数而非玩法
- **个性化事件**：基于玩家进度和行为定制不同事件和目标

**Monopoly Go 的事件体系**（搜索综合）：
- **四类主事件同时运行**：锦标赛（铁路得分）、Solo/Banner（个人里程碑）、Partner（合作项目）、Flash（短窗口高倍率）
- **事件堆叠策略**：多个事件同时运行且奖励可叠加，玩家要策略性选择优先级
- **季度主题叙事线**：如"Ever After"童话主题持续约2个月，给重复事件赋予叙事框架
- **里程碑难度曲线差异化**：前期奖励容易拿（吸引参与），后期极高难度（驱动付费）

### 应对策略模式库

#### 策略 F1：机制变异（同玩法 + 规则微调）

**核心思路**：保留玩家熟悉的核心操作，但每期改变 1-2 条规则参数，让策略需要重新计算。

**变异维度**：
| 维度 | 示例 | 效果 |
|------|------|------|
| 资源规则变异 | Boss战第2期：攻击需要2种代币组合而非1种 | 改变资源获取策略 |
| 目标结构变异 | Bingo第2期：必须完成特定图案而非任意行列 | 改变优先级选择 |
| 时间规则变异 | 某期活动前12小时奖励×1.5，后12小时×0.8 | 改变参与节奏 |
| 难度曲线变异 | 某期前松后紧 vs 某期前紧后松 | 改变付费压力点位置 |

**设计原则**：变异幅度要"让老玩家觉得有新策略可研究，但不需要重新学玩法"。

#### 策略 F2：奖励结构轮换（同玩法 + 不同奖励重心）

**核心思路**：每期的稀缺奖励不同，让玩家的"需要"发生变化。

**轮换方式**：
| 周期 | 稀缺奖励 | 玩家动机变化 |
|------|---------|-------------|
| 第1期 | 限定鱼竿 | 收集驱动 |
| 第2期 | 大量体力返还 | 效率驱动（体力用于其他活动） |
| 第3期 | 专属装饰/头像 | 社交炫耀驱动 |
| 第4期 | 其他活动代币 | 跨活动联动驱动 |

**Coin Master 参考**：Set Blast（卡牌收集+30%）和 Bet Blast（奖励×2）本质是"同一个核心循环，不同期给不同类型的加成"。

#### 策略 F3：乘数叠加事件（加成层而非新玩法）

**核心思路**：不改变活动本身，而是在活动外叠加一个"经济参数调整层"。

**典型实现**：
- **倍率事件**：某期所有循环I活动奖励×1.5（类似 Coin Master 的 Bet Blast）
- **折扣事件**：某期活动代币消耗减半（类似 Village Mania 建筑折扣）
- **稀有率提升**：某期目标活动鱼的出现概率从20%提升到30%

**优势**：开发成本极低（只改数值参数），但能有效改变玩家的经济计算和付费决策。

#### 策略 F4：跨活动联动（事件堆叠）

**核心思路**：让多个同期活动之间产生互动关系，而非各自独立。

**典型实现**：
- 循环I活动的某种产出变成循环III活动的额外次数
- 目标活动的特定阶段解锁循环I活动的隐藏关卡
- 社交活动的排名决定下一期循环活动的初始加成

**Monopoly Go 参考**：多事件同时运行且奖励可叠加，玩家在同一行为上获得多层奖励。

#### 策略 F5：个性化难度/目标

**核心思路**：不同玩家看到不同的目标和奖励，基于行为数据分层。

**分层逻辑**：
| 玩家类型 | 差异化策略 |
|---------|-----------|
| 新回归玩家 | 降低前几个阶段门槛，给"快速跟上"的感觉 |
| 高活跃免费玩家 | 提供"时间换奖励"的深度路径 |
| 海豚玩家 | 在第3-4阶段设置"差一点就够"的付费甜蜜点 |
| 鲸鱼玩家 | 提供额外的竞争性目标（专属排行榜） |

**Coin Master 参考**：事件基于玩家进度和行为定制不同目标。

#### 策略 F6：季度叙事主题线

**核心思路**：用 2-3 个月的叙事线串联多期活动，让重复活动有"连续剧"效果。

**典型实现**：
- 赛季主题（如"深海探险季"）持续 8-10 个周期
- 每期活动是故事的一个章节，有递进的背景叙事
- 赛季结束有终极奖励，前面每期的参与度影响终极奖励等级
- 新赛季 = 全新主题 + 重置期待感

**Monopoly Go 参考**："Ever After"童话主题持续约2个月，贴纸收集册与季度主题绑定。

### 新鲜感设计的优先级矩阵

| 策略 | 开发成本 | 预期效果 | 适用频率 | 优先级 |
|------|---------|---------|---------|--------|
| F1 机制变异 | 低 | 中——延缓衰减但不逆转 | 每期必用 | ★★★★ |
| F2 奖励轮换 | 低 | 中——改变动机但不改变体验 | 每期必用 | ★★★★ |
| F3 乘数叠加 | 极低 | 中高——改变经济计算 | 间歇使用（每3-4期一次） | ★★★★★ |
| F4 跨活动联动 | 中 | 高——创造新的策略层 | 每期可用（不同组合） | ★★★★ |
| F5 个性化 | 高（需数据+系统） | 高——根本性解决重复感 | 长期投入 | ★★★ |
| F6 季度叙事 | 中 | 高——给重复内容赋予意义 | 每季度一次 | ★★★★ |

> **核心原则**：新鲜感不等于做新玩法。行业最佳实践是"放大核心循环"而非"创造侧线"。F1-F4 的组合使用（低成本 + 高覆盖）是短期最优解；F5+F6 是长期解。

## 三、包装模式

### 模式 W1：主题包装

**定义**：用视觉主题包装底层玩法机制，相同机制可换主题复用。

**典型实例**：
- 破坏玩法 → 拳击主题
- 对对碰 → 西部牛仔主题
- Boss战 → 深海生物主题

**设计要点**：
- 主题必须与目标玩家的文化偏好匹配（方法论教训：IP联动调性不符 → 下沉≠低俗）
- 本项目目标用户是西方 40+ 男性，偏好写实、可辨识、有质感的视觉风格
- 主题与玩法之间要有逻辑关联（钓鱼游戏 → 海洋/户外/冒险主题自然适配）

### 模式 W2：Battle Pass 叠加

**定义**：在任何活动上叠加一层进度奖励轨道（免费轨 + 付费轨）。

**典型实例**：幸运转盘（内嵌 mini battle pass）、幸运卡牌（进度奖励）

**适用场景**：需要拉长活动参与周期、增加付费点的活动

**设计要点**：
- 免费轨必须有足够的吸引力（方法论：免费玩家"是否有事干"）
- 付费轨的价值差距不能让免费玩家感到被歧视（方法论：公平感）
- 进度推进速度要让活跃玩家在活动周期内能完成免费轨

### 模式 W3：新老玩家分轨

**定义**：同一玩法对新/老玩家使用不同的数值参数或关卡配置。

**典型实例**：魔药（新玩家数值表 / 老玩家数值表分离）

**适用场景**：核心循环类活动，新老玩家能力差距大

**设计要点**：
- 分轨的判断标准要简单明确（通常用账号等级或累计活跃天数）
- 新玩家轨道的难度曲线要更平缓（方法论：前期过度披露是误区）
- 分轨不能让老玩家感到"在帮新人养"

## 四、数值模式

### 模式 N1：有限次数 + 付费续命

**结构**：每天/每期给定 N 次免费机会 → 用完后付费购买额外次数

**典型实例**：Boss战、弹珠、靶场

**公平感控制**：
- 免费次数要足够让非付费玩家感到"有得玩"（方法论：日产出等价 20-50 美金付费产出）
- 付费次数要有上限封顶（方法论：限度封顶）

### 模式 N2：概率递增保底

**结构**：每次未中奖 → 概率递增 → 保底触发 → 概率重置

**典型实例**：幸运转盘、幸运卡牌

**设计要点**：
- 保底轮次必须明确设计，不能让玩家无限投入无产出
- 保底奖励的价值要配得上投入成本（否则破坏信任）

### 模式 N3：阶梯奖励 + 里程碑

**结构**：累积行为量 → 触发阶梯奖励 → 继续累积 → 触发里程碑大奖

**典型实例**：目标活动（鱼标类/信物类/材质类/特殊鱼类）

**设计要点**：
- 阶梯间距前密后疏（前期快速正反馈，后期挑战感）
- 里程碑大奖要有足够的"仪式感"（方法论：情绪释放的节奏）

### 模式 N4：多维养成膨胀

**结构**：新开系统 → 战力短时间大幅提升 → PVE 难度拉回稳态 → 拆分多维度分别包装

**典型实例**：方法论第2章描述的数值膨胀多维包装

**适用场景**：长线运营中，玩家成长到达瓶颈时

**设计要点**：
- 关键在于"玩家无法察觉效率回归"——每个维度的成长体验必须独立可感知
- 利用认知盲区而非欺骗——玩家的成长感是真实的

### 模式 N5：付费分层（多档消耗）

**结构**：同一活动提供多个消耗档位 → 不同付费能力的玩家自选档位 → 高档位消耗更多但奖励等比（或略折）放大 → 返利比基本不变

**典型实例**：
- 破坏（循环II）：三档——2代币/5代币/10代币同时开放
- 目标活动（C1）：体力>1000自动进入高消耗档位，约10倍消耗换8~10倍奖励

**适用场景**：需要拉高整体付费率的活动。付费分层让小R有参与感、大R有消耗出口，避免"一刀切定价"导致小R觉得贵、大R觉得不值

**设计要点**：
- **核心原则：返利比基本不变**——高档位不能给更高的单位回报，否则低档位玩家感觉被歧视
- 档位间消耗倍数建议 2~3 倍递增（如 2/5/10），梯度过小无意义，过大中间层没有合适档位
- 高档位奖励可适当打折（如10倍消耗给8倍奖励），这部分差值是大R为"效率"付费的溢价
- **数据验证**：破坏活动通过三档分层拿到循环II最高付费率（2.8%），说明分层设计对付费率有直接正向作用

## 五、社交模式

### 模式 S1：协作共建

**结构**：多人协作完成一个共同目标 → 协作过程中有角色分工 → 共享结果

**典型实例**：伙伴建造

**情绪维度**：社交协同产生目标感（方法论第1章）

### 模式 S2：异步竞争

**结构**：玩家各自完成行为 → 结果进入排行 → 周期结算奖惩

**典型实例**：排行榜活动、挑战赛

**设计要点**：
- 排行分层（生态位内公平竞争，方法论第3章）
- 奖励差距不能过大，保护中坚层参与动力

## 六、模式选择决策树

### 第一步：确定目标槽位

```
这个活动要填入哪个槽位？
├─ 循环I（核心玩法，3天，ARPU基准$0.33~$0.80）
│    → 消耗活动代币的策略型活动，C2模式
│    → 标杆参考：Boss战（$0.79）
├─ 循环II（次核心玩法，3天，ARPU基准$0.14~$0.29）
│    → 轻量低门槛的活动代币消耗出口，C2或C3模式
│    → 标杆参考：破坏（$0.29）
├─ 循环III（抽奖类+内置战令，3天，合计ARPU基准$0.75~$1.07）
│    → 随机性驱动 + 内置Battle Pass，C3 + N2（概率保底）+ W2（战令）
│    → 标杆参考：幸运魔术$0.44 + 魔术战令$0.41 = 合计$0.85
├─ 社交（社交玩法，3天，ARPU基准$0.07~$0.14）
│    → 社交粘性导向，C4 或 S1/S2，不以收入为目标
│    → 标杆参考：伙伴建造（$0.14）
└─ 新槽位 / 特殊活动
     → 先论证为什么现有7槽位不够，再定义新槽位的定位
```

### 第二步：匹配设计目的

```
设计目的是什么？
├─ 提供活动代币消耗出口 → C2（活动代币循环）
├─ 提升核心钓鱼体验 → C1（钓鱼概率触发，需慎重——直接影响核心循环节奏）
├─ 短期拉活/付费刺激 → C3（随机即时）
├─ 增强社交粘性 → C4（对抗循环）或 S1/S2
├─ 提升整体付费率 → C3 + W2（数据验证：循环III+战令是最强付费组合）
└─ 老玩家内容消耗 → C2 + N4（多维膨胀）
```

### 第三步：细化策略深度与分层

```
目标玩家分层？
├─ 全体玩家 → 优先 C2，避免高复杂度
├─ 付费玩家 → C3 + N1，配合 W2
├─ 社交活跃玩家 → C4 + S1/S2
└─ 新玩家 → C2（低难度）+ W3（分轨）

策略复杂度？
├─ 无策略（操控感幻觉） → C2（弹珠/靶场模式——玩家感觉能控制但结果随机）
├─ 极简 → C3（刮刮乐/转盘模式）
├─ 轻度 → C2（Bingo/拼图模式）
├─ 中度 → C2 + 策略性子玩法（Boss战/寻宝/对对碰模式）
└─ 重度 → C4（对抗型，谨慎使用，目标用户偏好简单）
```

### 收入提升方向参考

基于现有数据，不同策略对收入的影响：

| 策略 | 预期效果 | 数据依据 |
|------|---------|---------|
| 循环I增加策略性+目标感 | ARPU可向$0.50+看齐 | Boss战（$0.79）远超低策略性玩法，策略感+目标感是核心差异 |
| 循环I提升付费率至2%+ | ARPU显著提升 | Bingo 2.7%付费率 → $0.43 ARPU |
| 增加付费分层设计 | 付费率显著提升 | 破坏（三档分层）2.8%付费率为循环II最高，其他无分层活动付费率偏低 |
| 增加"选择即收益"的策略感 | 玩家参与深度提升 | 矿石寻宝（路径取舍）验证了"真实选择 → 更高参与感"，未来应多做此类设计 |
| 循环III + 战令联动 | 付费率可达3~5% | 战令5.5%付费率为全品类最高 |
| 社交活动叠加付费设计 | 效果有限 | 社交类ARPPU仅$4~$8，付费深度低 |

## 七、模式组合的注意事项

1. **单个活动不超过2个核心模式叠加**——否则复杂度爆炸（方法论：堆系统当内容是误区）
2. **模式叠加后必须重新验证 UE 清晰度**——组合后操作步骤是否超过3步？新玩家能否无引导理解？
3. **模式选择后必须过红线检查**——选择的模式是否服务核心循环？是否强迫玩家？是否冗余？
